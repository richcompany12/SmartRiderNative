## 2. v6 목록 (10-08 확정)

**A. 등록 안정화** (같은 이름 공용 건물 중복, 중요 표시가 저절로 켜진 일 — 10-02)
1. 저장·공용 올리기 버튼은 누르는 순간 잠금 (두 번 눌러도 한 번만)
2. 공용 저장 뒤 "저장됐어요, 사진을 추가하세요" 안내
3. 중요 버튼을 사진 버튼에서 떼고, 켜지면 주황색으로 확실히
4. 등록 화면을 다시 열 때 앞 건물의 중요 표시가 남지 않게
5. 등록할 때 50m 안에 비슷한 이름이 있으면 경고
6. 공용 올리기·어드민 상세 저장에서 옛날 비번 칸(password·publicMemo 등)이 같이 올라가지 않게 (10-05 서버에서 발견·삭제)

**B. 약관**
7. 약관 동의 창 — ✅ 준비 완료 (10-05). 사이드바·로그인 화면 이용약관 링크 / 앱 실행 시 동의 1회 / 동의 기록은 폰에만, 제보할 때만 동의 숫자가 같이 감 / 약관이 바뀌면 콘솔 숫자만 올려 다시 띄움 → v6 빌드 후 공기계 확인

**C. 화면 수정**
8. 지도 화면 위치저장 버튼: 하단바에 가려 절반만 보이는 문제 + 혼자 파란색인 것 정리
9. 상단 알림바 문구 정리: 개발용 초 표시 삭제 → **"건물 메모 알림 켜짐 · 내 건물 N곳"** / 위치 끊김 "위치를 잠시 못 받고 있어요 · GPS를 확인해주세요" / 시작 직후 "알림 준비 중..." (10-08 확정)
10. 단속카메라 화면 이름 "후면·양방향 카메라"로 통일 (데이터의 후면/양방향 구분은 그대로)

**D. 새 기능**
11. **볼륨 4단계** — 강력알림·토스트 따로 (지금은 2단계)
12. **블루투스 연결 시 헬멧으로만 소리** (내비 안내음 방식). 인터콤이 앞부분을 자르는 것 대비
13. **단지 영역 메모 (마스터 비번)** — 지도에 점을 찍어 영역 그리기. 등록: + 버튼·지도 길게 누르기 / 수정: 지도 영역 탭·건물 상세 카드·검색. **폰에만 저장**
14. **활동 지역 선택**
   - 업데이트 후 첫 실행 때 안내: "내 지역 카메라·건물 정보를 받으려면 활동 지역을 골라주세요"
   - 시·도 → 시·군·구, 최대 3곳, 사이드바/설정에서 변경
   - **"현재 위치로 자동 선택"은 절대 넣지 않음** (위치정보 원칙)
15. **라이더 통계 업로드** — 서버에 활동 지역 + 등록 건물 개수 + 마지막 접속일 + 앱 버전**만**. 건물 이름·메모·위치는 절대 안 올림. 바뀔 때만 올림 (접속일은 하루 1번, 날짜만)
16. **라이더 편의 정보 토스트** (화장실·생수·쉼터 등 **무료 정보만**)
   - 설정에서 라이더가 켜야 동작 (기본 꺼짐). 멈췄을 때 뜨는 일반 토스트 방식
   - 부드러운 알림음, 같은 지점 10분 안 중복 알림 금지
   - **돈 받는 제휴상점은 여기 절대 안 넣음**
17. **상점 광고는 앱 안에서만** — 지도 스폰서 핀, 건물 상세 "근처 라이더 혜택" 카드 (3장 "상점 광고")

## 3. 정해진 원칙

**출입정보(비번)**
- **메모1(도착 메모) = 비번. 서버에 절대 안 올린다.** 공용 건물이어도 내 폰에만
- **메모2·이름·샛길·특이사항 = 공용.** 모두에게 보이므로 비번 금지 (공용 저장 때 확인 창)
- 즐겨찾기·내 메모·내 폰 건물은 각자 폰에만 ("어느 건물에 자주 가는지"도 사생활)
- 이유: 서버에 비번이 모이면 "전국 현관 비번 DB" → 유출 시 주거침입 범죄. "개인 데이터는 내 폰에만"은 마케팅 자산

**서버 = 공용** — 서버의 건물은 전부 공용. 공용 등록은 어드민만, 일반 라이더는 내 메모만 덧씌운다

**위치정보** (10-08 확정)
- **라이더의 위치(좌표·경로)는 서버로 절대 보내지 않는다.** 비교는 전부 폰 안에서
- 근거: 위치정보지원센터 답변 (2026-10-08) — 폰 안에서만 처리하면 위치기반서비스사업 신고 대상이 아닐 수 있음. **위치를 서버로 보내는 순간 재검토**
- 데이터 내려받기는 **전체 또는 라이더가 고른 지역 단위.** 내 좌표로 서버에 조회하지 않는다
- 상점 광고 성과는 **상점별 숫자만** (어디서 노출됐는지 위치 전송 금지) / 특별판 주소 비교도 폰 안에서만
- 활동 지역은 라이더가 **직접 고른다.** 현재 위치로 자동 선택 안 함

**통계**
- 서버에 올리는 건 **숫자와 라이더가 직접 고른 값뿐** (활동 지역, 건물 개수, 접속일, 앱 버전)
- 지역별 파트너 발굴: 건물 개수가 많은 라이더에게 연락해 공용 건물 확대·영업 제안 (수익 배분은 직접 확인 후)

**광고 (애드몹 + 상점 광고)**
- **광고는 앱 안에서만.** 다른 앱 위에 뜨는 토스트·플로팅에는 광고 금지 (구글 정책: 앱 밖 광고 금지, 오버레이 포함). "제휴상점 혜택 확인" 같은 짧은 유도 토스트도 안 한다
- 애드몹: 등록 마칠 때 전면광고, 최소 3분 간격, 공유·백업 직후엔 안 띄움. 대표님 폰에서 진짜 광고 클릭·"광고 눌러줘" 금지 (계정 정지)

**상점 광고**
- 자리: 건물 상세 하단 **"근처 라이더 혜택" 카드**, 지도 **스폰서 핀**, 가게 페이지 (전부 앱 안)
- 내용은 라이더 혜택 중심: 생수, 라이더 할인, 화장실, 픽업 가이드
- **상권별 업종당 1곳, 상권당 3곳** 한정
- **1호 광고주: 웅이반점.** 처음엔 어드민이 직접 등록, 월 성과표 (노출·페이지·쿠폰 사용)
- 상점 광고는 모두에게 보여주고 **광고 끄기를 유료로 팔지 않는다.** 유료 회원 기능은 "내 메모 토스트"
- 위치 기반 혜택 표시는 개인정보처리방침에 명시
- **돈 받는 상점은 다른 앱 위 토스트에 절대 안 띄운다** (기존 원칙 재확인)
- 다른 앱 위 토스트는 **무료 라이더 편의 정보만, 라이더가 직접 켰을 때만**

**단속카메라**
- **후면 + 양방향만** (둘 다 후면번호판 촬영), 전면 제외
- 내비가 아니라서 **반대방향 짝은 1개만**
- **대표님 현장 등록이 경찰청 자료보다 우선** (두 번 울림 방지)
- 없어진 카메라는 자동 삭제 안 함 → 목록만 보고 대표님이 결정

**유료화·홍보** — 평생무료 약속 금지. 무료 = 알림바(건물 이름만) / 프로 = 토스트. 공개 문구는 "건물 메모"만 (비번을 연상은 되게, 권하지는 않게, 실제 단지명 금지)

**특별판** (스토어에 안 올리는 별도판)
- 같은 코드, 빌드만 따로 (패키지 이름 다르게). 둘 다 **접근성 화면 읽기**
  1. **부릉 콜창 키워드 검색**: 플로팅 탭 → 콜창 훑기 → 미니패널에 결과 → 하나 고르면 그 콜 위치로 굴려서 멈춤 → **수락은 반드시 라이더 손으로**
  2. **배민·쿠팡 목적지 미리 토스트**: 배차 화면 주소를 읽어 내 건물과 비교 → 도착 전부터 정보 표시
- **읽기만. 자동 수락·자동 클릭 절대 없음.** 고객 주소는 폰 안에서만 비교, 저장·전송 안 함
- 배포: 대표님이 직접 APK 설치, 비번으로 활성화, 기기 1대에 1개, Firebase에서 개인별·전체 원격 정지
- 애드몹 없음 (계정 보호). 상점 광고는 있음. **수익은 월 이용료**
- 설치 때 배민·부릉 **계정 불이익 가능성 미리 알림.** 플랫폼이 중단 요청하면 **즉시 중단**
- 전제: **읽기 테스트 먼저** (부릉·배민커넥트·쿠팡이츠 글자가 읽히는지, 앱이 막는지). 배민 새 앱 전환 후에
- 효과가 확실하면 스토어판에 **정직한 접근성 신고서**로 도전 검토. 구글 신고서에 용도를 숨기거나 꾸미지 않는다

**데이터 전략**
- 장기 목표: **전국 공용 건물 데이터.** 비번이 서버에 없으니 데이터 자체가 안전한 자산
- 팔기보다 **플랫폼·배달대행에 이용료 받고 연결(API)**. 라이더 앱은 모두에게 계속 열어둔다
- 이용약관에 **"제보한 공용 정보를 회사가 상업적으로 쓰고 제휴사에 제공할 수 있음"** 조항 필수 (나중에 소급 어려움 → **프로덕션 전에**)

**특별판** — 읽기 테스트 (배민 새 앱 전환 후) → 결과 보고 개발 여부 결정. 설치해줄 때 안드로이드 **"제한된 설정 허용"** 안내 필요 (스토어 밖 앱은 접근성 권한이 기본으로 막힘)

**그 밖에** — 피쉬라인 애드몹 / 명함 (문구는 대표님 확인 중) / 테스터 피드백 모으기 / **엘베 포스터** (실제 앱 화면, 서울·경기 전역, QR은 정식 출시 후)

**정식 출시 후** — 애드몹 스토어 연결·명함 배포 / 어드민 현황판 (처리방침·데이터 보안 먼저) / 상점 광고 1호(웅이반점) / 무료 일반 알림·엘리베이터 오차 필터·단속카메라 목록 자동 갱신 / 공용 건물 전국 확대 / 유료화

## 5. 보류 중인 일
- 공유 버튼 처리 (대표님 고민 중)
- 엘리베이터 안 단속 경고 오작동 (다른 작업과 묶어서)
- 자전거 라이더 토스트 지연 / 이름순 정렬 느림 (피드백 더 모이면)
- 진행방향이 맞을 때만 단속 경고 (먼 후보)
