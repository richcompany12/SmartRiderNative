## 2장. 광고 — "Test Ad"가 떠도 정상이다

- 대표님 폰은 **애드몹 테스트 기기로 등록**돼 있다. 진짜 광고 ID로 빌드해도 대표님 폰에선 "Test Ad"가 뜬다
- 스토어 AAB는 `false`(진짜 광고)로 빌드됐다
- 진짜 광고인지 확인하려면 **테스트 기기로 등록 안 된 테스터 폰**에서 본다
- 대표님 폰에선 광고를 절대 누르지 않는다

### 버전 올릴 때 순서 (3판 0장과 같음)

```
1. versionCode +1
2. adConfig.js  USE_TEST_ADS = false
3. gradlew.bat bundleRelease
4. D:\app\배포보관\ 에 날짜 붙여 복사
5. adConfig.js  USE_TEST_ADS = true   ← 3번 직후 바로. 습관으로
6. 커밋
```

- 5번을 빼먹으면: 개발용 APK에 진짜 광고 → 대표님이 누르면 애드몹 계정 위험
- 2번을 빼먹으면: 스토어에 테스트 광고 → 수익 0

- **개발 APK(공기계용)는 `true` 그대로 빌드한다.** `false`는 스토어 AAB 만들 때만 (13장)

### ⚠️ v3 올린 뒤 꼭 지킬 것 — 어드민은 v3로만

- 대표님·형님(어드민)은 **v3로 업데이트한 뒤에** 수정한다
- 급하게 v2로 고쳤다면 → Firebase 콘솔에서 `meta/alertsVersion`(또는 `buildingsVersion`) 숫자를 아무 숫자로 바꿔준다

## 7장. 유료화

- **토스트(도착 메모 자동 표시) = 유료**, 월 약 5천원 방향 (가격은 아직 공개 안 함)
- 초기 라이더는 **6개월~1년 무료** (인원·기간은 나중에 확정)
- **"평생무료" 약속은 모든 공개 자료에서 금지** — 소개 페이지·명함 전부 제거 완료
- 공개 문구는 "지금은 전부 무료 / 추후 월 구독 예정 / 먼저 시작한 분께 무료 기간"까지만
- 가치 논리: 모두의 편의가 아니라 **개인 라이더의 경쟁력.** 300~400건 쌓이면 효과가 난다
- 유료화는 **라이더가 가치를 느낀 뒤** (정식 출시 후)

### 무료/유료 알림 구분 (09-22 논의)

유료 전환 때 기존 라이더 이탈을 막기 위한 설계. **"편한데, 더 편한 게 유료"**.

```
도착 판정 (코틀린, 지금 그대로)
   ├─ 프로  → 지금처럼 다른 앱 위에 토스트
   └─ 무료  → 상단 알림바에 일반 알림 → 누르면 앱의 그 건물 상세로
```

- **일반 알림은 지금 앱에 없다 → 새로 만들어야 한다.** 알림 권한은 이미 받고 있다
- 무료 알림 내용: **건물 이름만** ("샘플오피스텔 도착 · 눌러서 메모 보기"). 메모는 안 보여준다
  - 이유 1: 메모까지 보이면 유료로 넘어갈 이유가 약해진다
  - 이유 2: 알림바는 **잠금화면에도** 보인다 → 잠금화면에선 건물 이름도 숨김 설정
- 등급 정보: 서버 `users/{uid}`에 `plan`(free/pro) + `expiresAt`(만료일) → 앱이 켜질 때 읽어 **폰에 저장** (오프라인에서도 유지) → 코틀린에 전달

**만들 것**
1. 도착 알림 채널 (소리·진동 단위)
2. 알림 띄우는 함수 (건물 이름만)
3. **알림 탭 → 앱 열고 그 건물 상세로** ← 제일 신경 쓸 곳
   - 앱이 떠 있을 때: 토스트 더블탭처럼 `reactHost`로 JS에 전달
   - 앱이 완전히 꺼져 있을 때: 앱이 켜지면서 "어느 건물 누르고 들어왔지?"를 따로 받아야 한다
4. 도착 판정 자리에서 분기: 프로 → 토스트 / 무료 → 2번

**시기:** versionCode 3에는 안 넣는다. 코틀린을 크게 건드리므로 정식 출시 후 따로 빌드·테스트.

### 결제 방식 메모 (09-22)

## 8장. 어드민 설계 (09-21 · 09-22 논의)

### 원칙
> **어드민은 "숫자"만 본다. 건물 이름·메모·위치는 절대 안 본다.**
> 공개 페이지에 "만든 저희도 볼 수 없습니다"라고 썼다. 어드민도 그 약속 안에서 만든다.

### 구조 — 웹 어드민, 리치캐노피와 분리

```
richcanopy.kr/admin              ← 리치캐노피 어드민 (그대로, 손대지 않음)

스마트라이더 Firebase 프로젝트 안에
  └─ 스마트라이더 어드민 웹 (별도 주소, 별도 배포)
       ├─ 강력알림 지점 (엑셀 일괄 입력 포함)
       ├─ 제보함 + 호별 안내도 이미지 올리기
       ├─ 라이더 현황판 (숫자만)
       ├─ 조건 팝업 · 원격 스위치
       └─ 구독·혜택 (유료화 때)

앱 안 어드민 → 현장에서 급할 때용으로 최소한만 (지점 하나 추가, 제보 확인)
```

**웹으로 가는 이유 (대표님)**
- 강력알림 업데이트는 경찰청 자료가 오든 안 오든 **사무실에서 차근차근** 하는 게 낫다
- 제보 처리 때 포토샵·채실장으로 **호별 위치 안내도**를 만들어 넣어야 한다 → 컴퓨터가 편하다

**리치캐노피 어드민과 합치지 않는 이유**
1. Firebase 프로젝트가 다르다 — 로그인·보안 규칙·저장소가 따로라 합치면 꼬인다
2. **형님 권한** — 합치면 캐노피 주문·장착점 쪽 문까지 열린다
3. 한쪽 빌드가 깨지면 다른 쪽도 멈춘다
4. 앱별로 **통째로 떼어 넘기거나 물려줄 수** 있어야 한다

"토탈 리치컴퍼니 어드민"은 나중에 **링크 모음 페이지** 하나로 충분하다. 합치지 않고 모아만 둔다.

### 기능 ① 라이더 현황판 — 가장 중요

라이더마다 서버에 **숫자 몇 개만** 올린다:

```
users/{uid}/stats
  ├─ buildingCount     건물 개수
  ├─ lastActiveAt      마지막 접속일
  ├─ appVersion        앱 버전
  └─ toastCountWeek    이번 주 토스트 뜬 횟수
```

- 올리는 때: 앱 켤 때 + 건물 저장·삭제 때. **숫자가 바뀌었을 때만** → 데이터 사용량 거의 0
- **토스트 횟수가 제일 값진 숫자** — 앱이 실제로 일한 횟수. 유료화 때 "이번 달 87번 먼저 알려줬어요"로 가치를 보여준다
- 첫 화면은 **분포**로:
  ```
  건물 0개      ← 설치만 하고 안 씀 → 많으면 사용설명서·첫 안내 부족 신호
  1~49개
  50~99개
  100~299개
  300개 이상    ← 유료화 1순위. 이 인원이 유료화 시작 타이밍을 알려준다
  ```
- ⚠️ 개수는 빈 건물로 부풀릴 수 있다 → 큰 혜택을 걸 땐 "최근 30일 등록 개수" 같은 조건 추가

### 기능 ② 조건 팝업·공지

```
popups/{id}
  ├─ 내용, 기간
  ├─ minBuildings: 100      건물 개수 이상
  ├─ minDays: 7             가입 후 며칠 이상
  └─ maxVersion             이 버전 이하에게만
```

- **조건 판단은 폰에서** 한다. 폰이 자기 개수를 이미 안다 → 가볍고 정확
- 예: 0개 → 사용설명서 링크 / 100개 넘음 → 감사 + 구독 예고 / 옛 버전 → 업데이트 부탁
- **지역 조건은 안 된다.** 위치를 안 올리는 약속

### 기능 ③ 원격 스위치 — 앱 업데이트 없이

| 스위치 | 쓰임 |
|---|---|
| 최소 버전 | 이보다 낮으면 "업데이트 해주세요" 창. 코틀린 큰 수정 후 필요 |
| 광고 켜기/끄기 | 문제 생기면 즉시 끄기 |
| 토스트 유료 전환 | 유료화 날짜에 스위치 하나로 |
| 링크 주소 | 사용설명서·문의 주소 바꿔도 앱 수정 없이 |

지금은 이게 없어서 뭘 바꾸든 심사를 거쳐야 한다.

### 기능 ④ 구독·혜택 (유료화 때)

- 라이더별 `무료 / 무료 기간(만료일) / 유료`
- "초기 N명 무료" → 가입 순서대로 자동 부여 + 수동 조정
- **심사 계정은 항상 pro 고정**

### 기능 ⑤ 권한 두 단계

| 역할 | 누구 | 할 수 있는 것 |
|---|---|---|
| 운영자 | 형님 | 제보 처리, 강력알림 지점, 공지 |
| 관리자 | 대표님만 | 구독·혜택, 원격 스위치, 라이더 현황 |

스위치 하나 잘못 누르면 전체 라이더에게 영향이 간다.

### 순서

```
1단계 (정식 출시 직후)   ① 현황판 + ③ 최소 버전 스위치
2단계 (라이더 50명쯤)    ② 조건 팝업

## 10장. 기억해둘 동작·현상

### 토스트가 뜨는 조건 (09-22 코틀린 확인 — 3판의 "5초"는 틀림)

| 항목 | 값 | 코틀린 |
|---|---|---|
| 위치 받는 간격 | 보통 5초, 빨라도 3초 | `LocationRequest.Builder(..., 5000L)` / `setMinUpdateIntervalMillis(3000L)` — **한 곳** |
| 체류 시간 | **3초** | `const val DWELL_TIME = 3000L` |
| 속도 기준 | 2.5 m/s(시속 9km) 미만 | `const val SPEED_THRESHOLD = 2.5` |
| 반경 | 설정값 (기본 20m) | JS가 `radius`로 넘김 |

```

getAllAlertPoints() → loadVersioned('alerts', 'alerts')

loadVersioned:
  ① meta/{kind}Version 확인 (4초)    실패 → 폰 저장본
