# 스마트라이더 테스트 피드백 기록

> 프로덕션(정식) 재신청 설문용. **버그 수정·기능 변경할 때마다 한 줄 추가.** 사실만 적는다.
>
> **출처는 넷 중 하나만:**
> - **테스터 제보** — 다른 테스터가 알려준 것
> - **테스터 실사용** — 대표님(테스터 겸 현직 라이더)이 직접 발견 (배달 현장 포함)
> - **내부 점검** — 코드 검토·공기계 테스트 중 발견
> - **테스터 기기 설치 시연 중 발견** — 대표님이 테스터 폰에 설치·시연하다 같이 본 것
>
> 출처가 불분명하면 **"출처 확인 필요"**로 적고 대표님께 묻는다. 테스터 제보가 아닌 것을 테스터 제보로 적지 않는다.
> 근거: 개발문서 3판·3-7판, 기획요약, git 기록 (10-11 정리).
